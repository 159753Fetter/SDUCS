#### 2.1 直线段的扫描转换算法

**数值微分（DDA)法**

左端点P0(x0,y0)，右端点P1(x1,y1)的直线段L(P0,P1)，斜率为k=(y1-y0)/(x1-x0)，画线过程为：从x的左端点x0开始，向x右端点步进，步长=1像素，即x每递增1，y递增k，取像素点(x,round(y))作为当前点的坐标，即(x,int(y+0.5)),取整的目的是为了取离真正交点近的像素网格点作为光栅化后的点。

注意：本节算法仅适用于|k|<=1的情形，因为在这种情况下，x每增加1，y最多增加1。

当|k|>1时，必须把xy的地位互换，y每增加1，x增加1/k。

**中点画线算法**

通过观察可以发现,画直线段的过程中，当前像素点为(xp,yp),下一个像素点有两种可选择点P1(xp+1,yp)或P2(xp+1,yp+1)。若M= (xp+1,yp+0.5)为P1与P2的中点,Q为理想直线与x=xp+1垂线的交点。当M在Q的下方时,P2应为下一个像素点;当M在Q的上方时，应取P1为**下一点**。

对直线L(p0,p1)采用方程F(x,y)=ax+by+c=0表示，a=y0-y1,b=xgt1-x0,c=x0y1-x1y0.

点和L的关系为：![image-20200820102906038](C:\Users\admin\AppData\Roaming\Typora\typora-user-images\image-20200820102906038.png)

所以，判断M在Q点的上方还是下方，只需将M带入F(x,y)并判断符号即可。
$$
d=F(M)=F(x_p+1,y_p+0.5)=a(x_p+1)+b(y_p+0.5)+c=F(x_p,y_p)+a+0.5b=a+0.5b
$$
所以d=a+0.5b，由于只需要符号用2d=2a+b摆脱小数。后续用增量计算：

d>=0:d1=d+a,增量为a，实际计算用2a，下一个点取右点
d<0:d2=d+a+b,增量为a+b，实际计算用2(a+b)，取右上点

**Bresenham算法**：误差项决定下一个像素

算法原理如下:过各行各列像素中心构造一组虚拟网格线,按直线从起点到终点的顺序计算直线与各垂直网格线的交点,然后确定该列像素中与此交点最近的像素。该算法的巧妙之处在于采用增量计算,使得对于每一列,只要检查一个误差项的符号,就可以确定该列所求的像素。

误差项d初值为0，x下标每增加1，d增加k。d≥0.5时，取右上像素，d-1；d<0.5时，取右方像素，d不动。

#### 2.3 多边形的扫描转换与区域填充

多边形有两种表示方法：顶点表示和点阵表示。顶点表示用多边形的顶点序列来表示多边形；点阵表示是用位于多边形内的像素集合来刻画多边形。光栅图形学的一个基本问题是把多边形的顶点表示转换为点阵表示，这种转换称为多边形的扫描转换。

#### 2.3.1 扫描转换

***扫描线算法——必考**

扫描线多边形区域填充算法是按扫描线顺序,计算扫描线与多边形的相交区间,再用要求的颜色显示这些区间的像素，以完成填充工作。区间的端点可以通过计算扫描线与多边形边界线的交点获得。

(1)求交。计算扫描线与多边形各边的交点。
(2)排序。把所有交点按x值的递增顺序排序。
(3)配对。将第一个与第二个、第三个与第四个等交点配对,每对交点代表扫描线与多边形的一个相交区间。
(4)填色。把相交区间内的像素置成多边形的颜色,把相交区间外的像素置成背景色。

改进：仅对与一条扫描线相交的多边形的边进行求交运算。

**边界标志算法**

先对多边形的每条边进行直线扫描转换,即对多边形边界所经过的像素打上标志;然后再采用和扫描线算法类似的方法将位于多边形内的各个区段着上所需颜色。对每条与多边形相交的扫描线依从左到右的顺序,逐个访问该扫描线上的像素。使用一个布尔量inside来表示当前点是否在多边形内。inside的初值为假,每当当前访问的像素是被打上边标志的点时,就inside取反。对未标志的像索，inside不变。若访问当前像素时,inside为真,说明该像素在多边形内,则把该像素置为填充颜色。

即：遇到已经标记的边上的点，就将inside取反，遇到未标记的点，就打上当前inside

#### 2.3.2 区域填充算法

区域可采用内点表示和边界表示两种表示形式。

内点表示中：区域内的所有像素着同一颜色
边界表示中：区域的边界点着同一颜色

区域填充指先将区域的一点赋予指定的颜色，然后将改颜色扩展到整个区域的过程。分为四连通区域和八连通区域。

**区域填充的递归算法**

内点表示的四连通区域的递归填充算法

```c++
void FloodFill4(int x,int y,int oldColor,int newColor) {      if(GetPixel(x,y) == oldColor) { 
    PutPixel(x,y,newColor); 
    FloodFill4(x,y+1,oldColor,newColor); 
    FloodFill4(x,y-1,oldColor,newColor); 
    FloodFill4(x-1,y,oldColor,newColor);
    FloodFill4(x+1,y,oldColor,newColor); 
 } 
}
```

**区域填充的扫描线算法**：减少递归层次

思想：当给定种子点(x,y)时，首先填充种子点所在扫描线上位于给定区域的一个区间，然后确定与这一区段相连通的上下两条扫描线上位于区域内的区段，并以此保存下来。反复这个过程，直到填充结束。

步骤：

1. 初始化：堆栈置空。将种子点（x，y）入栈。 

2. 出栈：若栈空则结束。否则取栈顶元素（x，y），以y作为当前扫描线。

3. 填充并确定种子点所在区段：从种子点（x，y）出发， 沿当前扫描线向左、右两个方向填充，直到边界。分别标记区段的左、右端点坐标为xl和xr。

4. 并确定新的种子点：在区间[xl,xr]中检查与当前扫描线y上、下相邻的两条扫描线上的象素。若存在非边界、未填充的象素，则把每一区间的最右象素作为种子点压入堆栈，返回第（2）步。 

上述算法对于每一个待填充区段，只需压栈一次；因此， 扫描线填充算法提高了区域填充的效率

**Cohen-Sutherland裁剪算法**

延长窗口的边，将二维平面分成9个区域，上下右左，外侧为1，内侧为0

裁剪一条线段时，先求出端点p1和p2的编码code1和code2：

1. 如果code1和code2均为0，则说明P1和P2均在窗口内，那么线段全部位于窗口内部，应取之。
2. 如果code1和code2经过**按位与**运算后的结果code1&code2**不等于**0，说明P1和P2同时在窗口的上方、下方、左方或右方，那么线段全部位于窗口的外部，应弃之。
3. 如果上述两种条件均不成立，则可按如?下方法处理：求出线段与窗口边界的交点，在交点处把线段一分为二，其中必有一段完全在窗口外，可以弃之。再对另一段重复进行上述处理，直到该线段完全被舍弃或者找到位于窗口内的一段线段为止。

### 2.5 反走样

用离散量表示连续量引起的失真现象称为走样(aliasing)，用于减少或消除这种效果的技术称为反走样(antialiasing)。常见方法有提高分辨率、区域采样和加权区域采样。

区域采样：MSAA——实际是模糊处理

当直线段与像素有交时，求出相交区域的面积，根据面积大小确定该像素的亮度值。简化计算采用离散的方法，将像素均分成n个子像索,然后计算中心点落在直线段内子像素的个数k,最后将屏幕中该像素的亮度置为最大灰度值乘以相交区域面积的近似值k/n。

从采样理论的角度考虑,区域采样方法相当于使用盒式滤波器进行前置滤波后再取样。即**先模糊后采样**

加权区域采样：

首先将像素均匀分割成n个子像素,则每个像素的面积为1/n;计算每个子像素对原像素的贡献,并保存在一张二维的加权表中;然后求出所有中心落于直线段内的子像素集Ω;最后计算所有这些子像素对原像素亮度贡献之和的值,该值乘以像素的最大灰度值作为该像素显示的最终灰度值。

### 2.6 消隐

为消除二义性，在绘制时消除被遮挡的不可见的线或面，习惯上称为消除隐藏线和隐藏面，或简称为消隐。经过消隐得到的投影图称为物体的真实图形。

**画家算法**

由远及近，先画远景，再画中景，最后画近景。

建立深度优先级表。根据每个多边形顶点z坐标的极小值zmin的大小把多边形作一初步的排序，zmin最小的多边形为P，进而与其他多边形Q进行检查。如果满足所有不遮挡条件，P不遮挡Q。如果测试失败，必须对两个多边形在xy平面上的投影作求交运算。计算时不必求出重叠部分，在交点处进行深度比较，只要判断出前后顺序即可。

只能处理互不相交的面，若遇到多边形相交或循环重叠，只能把相关面进行分割后再排序。

以被测点为圆心作单位圆，将全部有向边向单位圆作径向投影，并计算其弧长的代数和。代数和为0，点在多边形外部；代数和为2π，点在多边形内部；代数和为π，点在多边形边上。

法2：将坐标原点移到被测点，确定其他顶点所在象限。按照多边形的顺序判断所有顶点。同一个象限认为是0，跨过一个象限是π/2，跨过二个象限是π。逆时针为正。最后计算代数和，2π内部，0外部。
